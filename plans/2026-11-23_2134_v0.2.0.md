# v0.2.0 acceptance plan

Preserve the listener-independent API and static-first behavior. Require real tests for the following invariants:

- Immutable paths and metadata-only requests use snapshot lookup; live negative entries expire and remain bounded. Check actual requests, range bytes and immutable mutation detection.
- Publish routes atomically; validate declared overlaps and detect dynamic collisions. Check method overlap, slash boundaries, repeated replacement and SPA precedence.
- Drain real leases before disposing resources. Check delayed handler, delayed cancel, slow close and delayed startup under bounded waits.
- Validate Host and direct proxy peer trust; reject body/concurrency budget violations before side-effecting dispatch where possible. Check chunked bodies, per-plugin ceilings and absolute read deadlines.
- Count source completion, cancellation and errors; verify a paused large-file consumer does not eagerly consume the entire file.
- Run strict TypeScript, Node/Bun tests, coverage, packed-consumer checks and Chromium/WebKit media seeks. Gate release on installed upstream packages and their real protocol checks.
- Compare v0.1.0, native transport and v0.2.0 with separate server processes, matched workloads and payload verification. Report variation and avoid unsupported claims.
